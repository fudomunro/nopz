# Modal Demo

A minimal web page with a button that opens a modal dialog.

## Requirements

1. An `index.html` file exists and is the entry point.
2. The page contains a button element.
3. Clicking the button opens a modal/dialog.
4. The modal can be closed (via close button, Escape key, or clicking outside).
5. The modal uses semantic HTML (`<dialog>` element or `role="dialog"`).
6. The page includes basic CSS styling for the modal (overlay, centered layout).
